# Landing Page Interativa — Fanta

Landing page interativa desenvolvida como projeto de estudo em desenvolvimento Front-end.

O projeto utiliza HTML e CSS para construção e estilização da interface, além de JavaScript com GSAP e ScrollTrigger para criação de animações e efeitos visuais controlados pela rolagem da página.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger

## 📌 Funcionalidades

- Navegação visual na página
- Seção Hero com elementos gráficos e imagens
- Animações de elementos durante a rolagem
- Timelines de animação utilizando GSAP
- Efeitos de movimento, rotação e redimensionamento de elementos
- Seções de apresentação de produtos
- Botões de ação

## 🎨 Recursos utilizados

O projeto utiliza diferentes recursos de desenvolvimento Front-end, incluindo:

- Flexbox
- Posicionamento de elementos com `position`
- `z-index`
- Gradientes
- Transformações CSS
- SVG
- Fontes personalizadas com `@font-face`
- Unidades relativas como `vw` e `vh`
